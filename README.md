# SL-Uploader

Web page for sending a voice recording from an Android phone to the Smart Locket proof of concept over Bluetooth Low Energy.

- Open the GitHub Pages link in **Chrome on Android** (Web Bluetooth does not work in Safari on iPhone).
- Audio is converted on the phone to 16 kHz mono WAV (max 15 s). Nothing is uploaded to the internet; it goes straight to the locket.
- Open the locket before connecting: it only accepts uploads while open.
